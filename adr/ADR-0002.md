# ADR-0002: Selección de Arquitectura Monolito Modular

## Estado

Aceptado

## Fecha

03-09-2026

## Contexto

MediTriage es una plataforma orientada a reducir los tiempos de espera de los pacientes mediante una clasificación rápida y eficiente de la urgencia médica.

El sistema deberá permitir:

- Registro de síntomas de pacientes.
- Clasificación asistida de pacientes.
- Consulta de historial clínico.
- Gestión de usuarios y permisos.
- Auditoría de registros clínicos.

El equipo está compuesto por cinco integrantes y desarrolla un Producto Mínimo Viable (MVP), por lo que se requiere una solución que facilite el desarrollo inicial y reduzca la complejidad operativa.

Los principales atributos de calidad priorizados para el proyecto son:

1. Seguridad
2. Disponibilidad
3. Rendimiento

## Alternativas Consideradas

### Opción 1: Monolito Modular

Aplicación única organizada mediante módulos independientes que separan responsabilidades dentro de una misma solución.

### Opción 2: Microservicios

Arquitectura compuesta por múltiples servicios independientes comunicados entre sí.

## Decisión

Se adopta una arquitectura **Monolito Modular** para el desarrollo de MediTriage.

## Justificación

La arquitectura Monolito Modular fue seleccionada porque:

- Se adapta al tamaño actual del equipo.
- Permite desarrollar un MVP de forma más rápida.
- Reduce la complejidad de implementación y despliegue.
- Facilita el mantenimiento inicial del sistema.
- Permite una separación clara de funcionalidades mediante módulos.
- Ofrece una buena base para evolucionar la aplicación en futuras etapas.

Además, esta arquitectura permite satisfacer adecuadamente los atributos de calidad definidos para el proyecto.

### Seguridad

Facilita la implementación centralizada de autenticación, autorización y control de acceso a la información clínica.

### Disponibilidad

Reduce la complejidad operativa y disminuye los puntos de falla en comparación con arquitecturas distribuidas.

### Rendimiento

Disminuye la comunicación entre componentes, permitiendo respuestas rápidas para el proceso de clasificación de pacientes.

## Consecuencias Positivas

- Menor complejidad de desarrollo.
- Menor complejidad de despliegue.
- Curva de aprendizaje más simple para el equipo.
- Desarrollo más rápido del MVP.
- Mantenimiento inicial simplificado.

## Consecuencias Negativas

- Escalabilidad menos flexible que una arquitectura basada en microservicios.
- Mayor dependencia entre módulos dentro de la misma aplicación.
- Posible aumento del acoplamiento si no se respetan los límites entre módulos.

## Decisión Final

El equipo selecciona una arquitectura Monolito Modular como base para el diseño y construcción de MediTriage debido a que ofrece el mejor equilibrio entre simplicidad, mantenibilidad y cumplimiento de los atributos de calidad definidos para el proyecto.
